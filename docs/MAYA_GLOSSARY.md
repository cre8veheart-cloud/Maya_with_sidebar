# MAYA Engineering Glossary

A small shared vocabulary for the MAYA build.

## Cruft
Stale, redundant, obsolete, or superseded technical material that once had a purpose but now makes the active system harder to understand or maintain.

**CTO rule:** Preserve useful history in Git; remove cruft from the active working surface.

## Claude phruuuumpppft
Founder shorthand for excessive AI-generated cruft: redundant handoff documents, stale deployment notes, duplicate instructions, abandoned scaffolding, and other artifacts that create more archaeology than engineering value.

**Diagnostic question:** “Why are there 14 markdown files explaining a deployment from six weeks ago?”

**Treatment:** Keep anything that remains operationally authoritative; delete or consolidate the rest. Git history is the archive.
